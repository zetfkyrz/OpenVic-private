# План: цельные дивизии и обучение войск по шаблонам (как в Hearts of Iron IV)

Решение владельца (2026-11-20): дивизия — **одно целое**; её скорость — скорость **самого медленного полка** (кавалерия в составе дивизии
не уходит вперёд); найм — как в HOI4: **обучение по шаблонам** в очереди страны.

## Что сейчас
- Армия (`ArmyInstance`) состоит из дивизий (`DivisionInstance`, полки с `division_id`; шаблоны — `DivisionTemplate`, `docs/WAR_ASSUMPTIONS.md`,
  раздел 6). Скорость армии уже равна самому медленному полку (`UnitInstanceGroup::get_movement_speed`).
- **Почему кавалерия всё равно бежит вперёд:** полки отрываются от дивизий в отдельные армии, и армия из одной кавалерии идёт со скоростью
  кавалерии. Места, где это происходит:
  - ИИ собирает десант, отрывая по одному полку от большой армии (`ai/CountryAI.cpp`, `split_regiment`);
  - игрок может отделить полк (игровое действие `split_regiment`);
  - полки вне дивизий (резерв армии, полки без места в шаблоне) живут и ходят сами;
  - новые полки, набранные по одному (обычный набор), появляются отдельными армиями и ждут, пока их вольют в дивизию.
- Найм: заказ **полка** в провинции из конкретного попа-солдата (срок, товары со склада, лимит в месяц, приоритеты, мобилизация —
  `docs/RECRUITMENT.md`); есть набор **дивизии по шаблону** — все полки шаблона заказываются сразу и появляются вместе одной армией.

## Цельная дивизия (этап A1)
- **Единица движения и приказов — дивизия.** Армия идёт со скоростью самого медленного полка всех своих дивизий (так и есть); отдельный
  полк вне дивизии больше не может быть армией сам по себе.
- `split_regiment` для игрока заменяется на **«отделить дивизию»** (`split_division`, уже есть) и «перевести полк в резерв»; полк из резерва
  только вливается в дивизию (заполняет пустую ячейку шаблона) или расформировывается.
- ИИ десанта собирает силу **из дивизий** (`split_division_unit`), а не из полков.
- Отступление, окружение, фронты — уже по дивизиям (`War.cpp`, `Front.cpp`), проверить, что нигде не остаётся разбиения по полкам.
- Полки, набранные поштучно (старый набор, пополнения), **не ходят сами**: ждут в провинции набора в резерве, пока их не вольют в дивизию
  (сами — при ежедневной раскладке `update_all_divisions`, или игрок кнопкой).
- Скорость дивизии видна в окне армии («скорость: по самому медленному полку — …»).

## Обучение по шаблонам (этапы A2–A4)
### Очередь обучения страны (вместо заказа полков по провинциям)
- Строка очереди: **шаблон**, **число дивизий**, **место развёртывания** (провинция или «столица»), приоритет. Строки идут сверху вниз.
- Каждая дивизия строки проходит **обучение**: срок — самый долгий срок полков шаблона (как сейчас), прогресс виден в процентах.
- **Люди**: при начале обучения берутся из попов-солдат страны (решение 2026-11-06: полк — 3000 человек из солдат); где брать — см. вопрос 1.
- **Снаряжение**: товары полков шаблона (ружья, артиллерия, лошади — `docs/RECRUITMENT.md`) идут со склада **по ходу обучения**, по
  дням; нет товара — обучение стоит (видно, чего не хватает).
- **Лимит**: одновременно обучается не больше N дивизий (по законам, по военным заводам или по «лагерям» — см. вопрос 3); лимит набора в
  месяц сейчас — `RECRUIT_MAX_REGIMENTS_PER_MONTH`.
- **Готовая дивизия** появляется в месте развёртывания одной армией (как набор по шаблону сейчас), с опытом обучения.
- **Досрочный выпуск** (как в HOI4): дивизию можно выпустить раньше — с неполным опытом и с той частью снаряжения, что уже получена (меньше
  силы и организации).
- **Опыт обучения**: дивизия после полного обучения — уровень «обученные»; позже — учения в мирное время (тратят товары, растёт опыт).

### Шаблоны
- Шаблоны уже есть (окно шаблонов дивизий, `DivisionTemplatesWindow.gd`). Добавить: срок обучения, людей и товары шаблона в окне,
  кнопку «Обучать» из окна шаблона.
- Изменение шаблона меняет обучающиеся дивизии: недостающие полки учатся дольше, лишние — снимаются (как с готовыми дивизиями).

### Мобилизация и ИИ
- Мобилизация остаётся (полки из бедных попов без снаряжения), но тоже **дивизиями шаблона мобилизации** — самого дешёвого, без
  кавалерии и артиллерии.
- ИИ ставит в очередь дивизии по своему первому шаблону (как сейчас набор по шаблону), с учётом склада и людей; в войне — с высоким
  приоритетом, досрочный выпуск при угрозе (враг рядом со столицей).

## Интерфейс
- Окно набора (F7) — вкладка **«Обучение»**: очередь (шаблон, число, место, прогресс, нехватка людей и товаров, кнопки «вверх», «вниз»,
  «отменить», «выпустить досрочно»), внизу — «добавить в очередь» (шаблон, число, место).
- В окне армии: скорость дивизии, опыт, полки резерва (влить, расформировать).
- Старый поштучный набор полков остаётся только для кораблей (до своего этапа флота).

## Этапы
- **A1 — цельные дивизии**: запрет армий из одиночных полков (игрок, ИИ десанта, резерв, поштучный набор), скорость в окне армии.
- **A2 — очередь обучения**: строки по шаблонам, прогресс, люди при начале, товары по дням, развёртывание, отмена; ИИ на очередь.
- **A3 — досрочный выпуск и опыт обучения**; изменение шаблона во время обучения.
- **A4 — мобилизация дивизиями**, учения в мирное время.
- Проверки каждого этапа: самотесты (дивизия не делится, скорость = самый медленный полк; обучение выдаёт дивизию шаблона в срок; нет
  товара — стоит; досрочный выпуск — неполная сила), детерминизм 1/3/8/16 потоков, прогон ИИ на 2 года (армии, войны), окно в игре.

## Вопросы владельцу (до начала A2)
1. Людей для обучения брать **из всех попов-солдат страны** (как пул людских ресурсов HOI4) или из солдат **провинции/области
   развёртывания** (как сейчас набор)?
2. Поштучный набор полков убрать совсем (только дивизии шаблонов) или оставить для пополнения неполных дивизий?
3. Чем ограничить число одновременно обучаемых дивизий: законом, числом казарм/лагерей (новое здание), военными заводами или только
   людьми и товарами?
4. Снаряжение — списывать по дням обучения (как HOI4) или сразу при начале (как сейчас)?
