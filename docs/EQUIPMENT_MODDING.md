# Оружие армии: как менять баланс и добавлять своё одними файлами

Оружие (винтовки, полевая артиллерия) и его товары описаны данными, не кодом. Тут: где лежат файлы, формат, как поменять баланс, как добавить новое поколение
или целую новую линию (осадная артиллерия, пулемёты) без правки C++, как подключить свою систему технологий. Числа по умолчанию и допущения — в [WAR_ASSUMPTIONS.md](WAR_ASSUMPTIONS.md).

## 1. Где лежат файлы

```
ov_data/                                   встроенный корень данных OpenVic (в репозитории рядом с game/ и extension/)
  common/
    ov_equipment/
      lines.txt                            виды оружия («линии»): rifle, field_artillery, ...
      rifles/rifle_1.txt ... rifle_4.txt   по одному оружию на файл
      artillery/field_gun_1.txt ... field_gun_4.txt
      provisional_unlocks.txt              ВРЕМЕННАЯ заглушка разблокировок по году (подпункт 3)
    ov_production_types/<id>.txt           рецепт производства оружия, по файлу (подпункт 5)
  localisation/ov_equipment.csv            названия оружия и линий RU/EN (подпункт 4)
```

Корень `ov_data` грузится **после** Vic2 и **до** модов. Мод кладёт файл с тем же путём (`<мод>/common/ov_equipment/rifles/rifle_2.txt`) и перекрывает встроенный;
файл с новым путём добавляется. Если у оружия из мода тот же `id`, что у загруженного, оно заменяет его (в логе строка `Weapon "x" of <файл> replaces the one of <файл>`).
Папку Vic2 не трогаем. Где ищется `ov_data`: параметр `--ov-data <папка>` у headless, переменная окружения `OPENVIC_DATA_PATH`, иначе папка `ov_data` в текущей
папке, рядом с исполняемым файлом или в одной из родительских. Игра в редакторе берёт `<репозиторий>/ov_data`; в собранной игре папку кладут рядом с exe.

Порядок загрузки не зависит от файловой системы: сначала Vic2, потом `ov_data`, потом моды по порядку; внутри корня файлы отсортированы по пути. Любой файл можно сломать
безопасно: файл с синтаксической ошибкой, неизвестной линией, пропущенным обязательным ключом или значением вне диапазона пропускается с предупреждением (файл, строка, причина),
остальные грузятся, игра не падает. Неизвестный ключ — предупреждение, остальное из файла читается.

## 2. Виды оружия: `lines.txt`

```
rifle = {
	icon = "small_arms"                      ключ значка линии
	name = "EQUIPMENT_LINE_RIFLE"            ключ локализации
	slot = infantry                          слот шаблона: infantry, cavalry, support, special
	unit_types = { infantry guard irregular engineer dragoon }   типы полков (units/*.txt), которые пользуются этим оружием
}
```
Новая линия — ещё один блок здесь и файлы её оружия в любой подпапке `ov_equipment`.

## 3. Оружие: один файл — одно оружие

Папка внутри `ov_equipment` значения не имеет (только порядок: `rifles`, `artillery`, `siege`, ...). Каждый файл — блок с именем `id` оружия. Пример (`rifles/rifle_3.txt`):

```
rifle_3 = {
	line = rifle                  вид оружия (ключ из lines.txt)
	tier = 3                      поколение, 1 и больше
	unlock_key = "equipment:rifle_3"   разблокировка страны, при которой оружие доступно (по умолчанию equipment:<id>)
	rof = 7                       выстрелов в минуту
	range = 500                   дальность, метры
	canister_range = 300          (необязательно) дальность картечи, метры
	accuracy = 0.65               0..1
	reliability = 0.88            0..1
	ammo_per_day = 0.040          расход ammo_good на изделие в день боя (необязательно)
	ammo_good = "ammunition"      товар патронов (необязательно; поколения патронов — позже)
	weight = 4.2                  килограммов одного изделия
	cost = { rifle_3 = 1 }        цена изделия в шаблоне, товарами
	flags = { breech_loading }    breech_loading, magazine, smokeless, indirect_fire, canister, shrapnel (список открытый)
	good = {                      товар, которым является оружие; загрузчик регистрирует его сам (подпункт 4)
		id = "rifle_3"            (по умолчанию id оружия)
		replaces = "small_arms"   (необязательно) товар Vic2, который становится этим товаром (псевдоним старого имени)
		base_price = 80           базовая цена на рынке
		icon = "small_arms"       ключ значка товара
		name = "rifle_3"          ключ локализации названия
		colour = { 222 142 34 }   цвет товара
	}
}
```
Обязательные ключи: `line`, `tier`, `rof`, `range`, `accuracy`, `reliability`, `weight`, `good.base_price`. Всё, что не указано, берёт значение по умолчанию.

## 4. Как поменять баланс

Правка одного числа в одном файле: например, чтобы сделать `rifle_2` дальнобойнее, открой `ov_data/common/ov_equipment/rifles/rifle_2.txt` и поменяй `range`.
Мод делает то же, кладя в свою папку файл по тому же пути. Цены — `good.base_price`. Все коэффициенты боя и шаблонов (веса линий, плотность, пределы шаблона) — не в этих файлах,
а в группах `ov_war` / `ov_economy` файла `common/openvic_defines.lua`.

## 5. Как добавить новое поколение и новую линию

Новое поколение винтовки (rifle_5): файл `ov_data/common/ov_equipment/rifles/rifle_5.txt` с `line = rifle`, `tier = 5`, своим `good` и `unlock_key` (по умолчанию
`equipment:rifle_5`). Новая линия, например осадная артиллерия:

1. В `lines.txt` блок:
   ```
   siege_artillery = { icon = "artillery" name = "EQUIPMENT_LINE_SIEGE" slot = special unit_types = { siege_gun } }
   ```
2. Файл `ov_data/common/ov_equipment/siege/siege_1.txt`:
   ```
   siege_1 = {
   	line = siege_artillery
   	tier = 1
   	rof = 0.5
   	range = 3000
   	accuracy = 0.4
   	reliability = 0.9
   	weight = 2000
   	good = { base_price = 120 }
   }
   ```
3. Перезапустить игру. Оружие подхватится без правки кода (автотест `equipment: a weapon of the new line is loaded without code` проверяет именно это).

Дальше (подпункты 3–6) к оружию добавляются разблокировки, рецепты производства и показ в шаблоне; новое оружие по тем же файлам попадёт и туда.
