# Стенд для замеров в игре без рук

Запускает игру из папки проекта, подставляет в `GameSession.gd` кусок GDScript из `bodies/`, делает скриншоты и печатает строки `DEVCHECK` в лог.
Не коммитьте подставленные файлы (стенд сам возвращает их командой `git checkout`).

```bash
VK_LOADER_LAYERS_DISABLE='~implicit~' OV_SIM_THREAD=1 tools/dev_harness/run_dev.sh bodies/spikes.gd out/spikes.log
grep DEVCHECK out/spikes.log
```

| тело | что измеряет |
|---|---|
| `bench.gd` | тест производительности F12 на 60 секунд и отчёт в `%APPDATA%\OpenVic\perf` |
| `spikes.gd` | сколько кадров дольше 12/20/40 мс на самой быстрой скорости, 45 секунд |
| `dense.gd` | стоимость кадра, когда в кадре много моделей; потом с остановленной анимацией и со скрытыми моделями |
| `animation_culling.gd` | кадр вблизи с отсечением по камере (строка «старое поведение» после перехода на ручное управление анимацией больше не сравнима) |
| `bisect_process.gd` | выключает узлы по очереди и показывает, какой из них стоит кадра |
| `frames.gd`, `clock.gd`, `cpu_sampler_cost.gd` | кадр на паузе/на скорости, часы симуляции, стоимость замера процессора |

Скриншоты лежат в `out/dev_shots`. Заметка: окно открывается 1920×1080 в точке 0,0 (нужен экран побольше). Тела — это код, который вставляется внутрь функции, с отступом табуляцией.
